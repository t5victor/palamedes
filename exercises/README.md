# PALAMEDES Exercises

Each assigned exercise lives in its own directory and has an `exercise.md` file before it is presented:

```text
exercises/<domain>/<exercise-id>/
    exercise.md
    fixtures/   # when file-based inputs are needed
    work/       # when meaningful learner artifacts are produced
```

`exercise.md` states the objective, operational context, inputs, exact tasks and deliverables, relevant constraints/tools, and completion criteria. Keep supplied inputs in `fixtures/`; preserve only meaningful learner work in `work/` (not every command or transient output). See `METHODOLOGY.md` for the complete workflow, review, and completion record rules.

Do not create placeholder exercises or a large backlog. No exercise files exist yet.
